03 — SECURITY

Trust built into the contract, not promised in a tweet.

Three properties are enforced by code and verifiable by anyone reading the contract on-chain.

✕

No minting after launch

The entire 10B supply is created once, in the deployment transaction. There is no function — hidden or public — that can create more NTL afterward.

✕

No burn mechanism

Nobody, including the project team, can destroy NTL from any wallet. The circulating supply only ever moves — it never shrinks.

✓

Ownership renounced

Once initial liquidity is in place, contract ownership is permanently renounced, removing any administrative control over the token.

04 — ROADMAP

From contract to a running world.

Each phase gates the next — we don't move to real funds or a public listing until the phase before it is complete.

Phase 1

Contract & testnet deployment

NTL token contract written, compiled, and deployed to BNB Smart Chain Testnet for verification.

Phase 2

Independent security audit

Full contract audit by an external firm, with the report published publicly before any mainnet activity.

Phase 3

Mainnet deployment

Contract deployed to BNB Smart Chain mainnet and verified on BscScan.

Phase 4

Liquidity & ownership renouncement

Initial liquidity added on PancakeSwap and locked; contract ownership permanently renounced.

Phase 5

World simulation, early access

First playable slice of the simulated world, with NTL as its native currency.

Phase 6

Community governance

Decisions about the world's development handed to NTL holders through on-chain governance.
